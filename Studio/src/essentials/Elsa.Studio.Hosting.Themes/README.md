# Elsa.Studio.Hosting.Themes

Optional server-side Studio Theme Store, directory theme sources and material assets. References Hosting/Api/Core; no Web or Nuplane dependency. Public composition is AddElsaStudioThemes; feature IDs remain ThemeStoreCore, ThemePicker and ThemeManagement. Existing Themes configuration keys and JSON formats are retained, with independent StoreFile and AssetsDirectory choices.

Implementation and qualification are in progress under Program3340 task3360 and spec1011. This is not a publication/release request. Managed-state/read-projection separation and initial public-host composition are qualified. Web adoption, remaining behavioral/runtime qualification and delivery gates are still outstanding.
