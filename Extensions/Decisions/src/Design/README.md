# Decisions Design

`DecisionDesignService` is the host-authorized entry point for reusable assets, immutable publication, cloning, saved expectations, exact evaluation and completed test receipts. `DecisionsDesignFeature` registers it and the options snapshot. The host installs a compiler/evaluator, persistence provider and access policy. Missing authorization or persistence fails explicitly as unavailable; no permissive authorization or synthetic empty store is supplied.

`IDecisionAccessPolicy` receives the trusted tenant/persisted subject and the operation/resource. `UseDecisionsAccessPolicy<TPolicy>` installs a provider default while preserving an explicit host replacement; competing policies fail during registration. HTTP uses Foundation's normalized principal and canonical permission evaluator. Identity-free applications using supplied artifacts call Core/evaluator directly instead of this protected authoring entry point.

Source is authoritative XML retained verbatim. An update supplies a complete expected-revision source replacement; the normal table editor patches the retained document instead of rebuilding a reduced model. Well-formed unsupported XML can be retained and downloaded with source permission, while compiler eligibility remains separate and publication refuses unsupported semantics. Malformed XML, DTDs, excessive size/depth and invalid source revisions are refused. Metadata-only edits retain the supplied original source bytes.

A test copies exact candidate and case revisions into request memory and evaluates synchronously under a shared one-million-operation budget. It then atomically writes one completed receipt. There is no accepted pending test job, recovery coordinator or scheduler. Existing completed operations replay before mutable case reads; otherwise changed/deleted original revisions conflict. Concurrent equivalent pure computation is harmless and receipt uniqueness chooses one result.

Completed history keeps identities, hashes and safe comparisons by default. Detailed expected/actual values and original case inputs are returned transiently to authorized callers; retaining them requires the host's `RetainDetailedTestHistory` opt-in. Summary-only replay reports `hasDetailedPayload=false` and never reconstructs deleted details by evaluation. Protected history checks current sensitive-value permission; deleting a run keeps only its operation tombstone and cannot recreate its payload. Case and published-version sensitivity is captured independently of later draft changes.

No event handler, background task or recurring cleanup is registered.
