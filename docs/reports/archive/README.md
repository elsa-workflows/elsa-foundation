# Archived reports

Point-in-time reports that are no longer current: superseded by later reports, folded into ADRs or
the constitutions, or older than 2026-08 with no live reader. They stay in the tree so links still
resolve and so a reader can see what a decision looked like at the time.

- Git history is authoritative. A report's last commit (`git log -1 -- docs/reports/archive/<file>`)
  is its date; nothing here is maintained.
- Archived reports may cite paths, projects, specs, or scripts that no longer exist.
- Do not link new work here. Current findings live in [`../README.md`](../README.md).
