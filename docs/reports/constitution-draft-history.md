## Reading Rule

Use this report family to answer "how did this rule get here?" or "which draft decision does this section preserve?" Use the constitution files themselves for gates, allowed exceptions, ratification state, and governance.

Do not copy definitions or gate language from these reports into new documents. Link to the constitution, glossary, reference docs, or reports layer that owns the material.
