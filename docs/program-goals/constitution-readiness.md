# Constitution Readiness

Status: active.

Area: targeted constitution review / ratification readiness.

Steward(s): Joey plus active architects/agents.

## Purpose

Track targeted constitution work needed for launch without turning draft constitutions into a giant ratification project.

The constitutions remain the quality-gate layer. This bucket exists to keep remaining draft, provisional, unratified, or non-gate material visible while enforcing the rule that constitution work should be targeted to a selected work unit or launch-blocking ambiguity.

## In Scope

- Targeted Critical Constitution Review for gates needed by approved work.
- Safe thinning where explanatory material already has a glossary, reference, report, or spec home.
- Ratification-readiness notes for draft/provisional sections.
- Clarifying which constitution text is gate, exception, governance, placeholder, or unresolved decision.

## Out Of Scope

- Broad ratification of all constitution sections in one pass.
- Moving glossary meanings into constitution text.
- Recording roadmap items in constitution files.
- Runtime execution seam decisions before the runtime architect has reviewed the seam.

## Active Objectives

1. Use Critical Constitution Review only for targeted gates needed by an approved work unit.
2. Keep broad draft/provisional status visible without treating it as the next task by default.
3. Move explanatory or historical material out only when the destination source-of-truth layer is clear.
4. Keep unresolved architecture decisions in reports/specs until ratified.

## Current Roadmap Notes

- Do not start with broad ratification.
- Warn users when draft/provisional constitution status matters to the task.
- If a user wants to focus on unratified items, start a targeted work unit using Critical Constitution Review and Work Unit Planner.
- Runtime/design gates should be reviewed in connection with the Runtime Execution Seam bucket.
- Configuration/appsettings gates should wait for feature composition evidence to stabilize.

## Drift / Review Notes

- Constitution readiness supports hard work units; it should not become a substitute for them.
- If a review produces a ratified gate, move the gate into the constitution and leave links from the originating report or bucket.

## Removal or Completion Conditions

Complete or pause this bucket when launch-blocking constitution ambiguity is resolved, remaining draft items are intentionally deferred, and future constitution work is attached to specific program goals or specs.
