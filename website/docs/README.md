# Elsa 4 documentation

This documentation source lives with the Elsa Foundation code and is reviewed through its GitHub workflow. This GitBook space is the reader-facing entry point for the guidance available here.

Choose a path:

- [Essentials](essentials/README.md) for running the reference server and understanding its architecture.
- [Extensions](extensions/README.md) for optional modules and their extension points.
- [Studio](studio/README.md) for the visual client and the documented Workbench pairing.

The repository is developing Elsa 4 preview software. Check each guide against the Elsa version you use; a guide on the default branch may describe current development rather than a released package.
