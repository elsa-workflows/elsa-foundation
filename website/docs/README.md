# Elsa 4 documentation

Elsa lets you describe a workflow, publish it, run it, and inspect what happened. Elsa 4 is preview software. These pages introduce the reference server and visual client, with a small local workflow you can try.

Using Elsa 3? Continue with the [Elsa 3 documentation](https://docs.elsaworkflows.io/). Check the version before applying an Elsa 4 example to an existing application.

Choose a path:

- [Try Elsa locally](essentials/quickstart.md), then [create your first workflow](essentials/first-workflow.md).
- [Essentials](essentials/README.md) for the server, source-build instructions, and architecture.
- [Extensions](extensions/README.md) for optional modules and their extension points.
- [Studio](studio/README.md) for the visual client and the documented Workbench pairing.

`Elsa.Workbench` is a reference host that composes Elsa features. A custom host can include a different set of capabilities. Studio is the visual client used with that server; check the server and Studio versions together.

The quickstart uses an explicitly recorded image pair. Other source guides may describe current development rather than a released package. Each verification record applies to its named revisions and environment.

These pages are maintained in the Foundation repository. [Propose a documentation change](contributing/README.md) through GitHub.
