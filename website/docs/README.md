# Elsa 4 documentation

Elsa lets you describe a workflow, publish it, run it, and inspect what happened. These pages introduce the reference server and visual client, with a small local workflow you can try.

> **Elsa 4 is preview software.** Labels and behaviour can change between previews. Each guide's verification applies to the revisions and environment it names, and some source guides describe current development rather than a released package. Always check that your server and Studio versions match each other and the guide.

Using Elsa 3? Continue with the [Elsa 3 documentation](https://docs.elsaworkflows.io/). Check the version before applying an Elsa 4 example to an existing application.

Choose a path:

- [Try Elsa locally](essentials/quickstart.md), then [create your first workflow](essentials/first-workflow.md).
- [Essentials](essentials/README.md) for the server, source-build instructions, and architecture.
- [Extensions](extensions/README.md) for optional modules and their extension points.
- [Studio](studio/README.md) for the visual client and the documented Workbench pairing.

`Elsa.Workbench` is a reference host that composes Elsa features; a custom host can include a different set. Studio is the visual client used with that server. The quickstart uses a pinned, recorded image pair.

These pages are maintained in the Foundation repository. [Propose a documentation change](contributing/README.md) through GitHub.
