# Elsa Studio

Elsa Studio is the visual client used with an Elsa server. The Foundation [Docker quickstart](https://github.com/elsa-workflows/elsa-foundation/blob/main/docker/compose/README.md#quick-start--published-images-no-clone-or-build) documents the published Workbench and Studio reference pairing and its connection settings.

Studio's client source is maintained alongside the server in the Foundation repository. See the [Studio overview](https://github.com/elsa-workflows/elsa-foundation/blob/main/Studio/README.md) and [Studio contribution guide](https://github.com/elsa-workflows/elsa-foundation/blob/main/Studio/CONTRIBUTING.md). Check the server and Studio versions together when setting up a deployment.
