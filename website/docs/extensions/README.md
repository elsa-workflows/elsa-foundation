# Optional modules

Elsa Foundation keeps optional modules under `Extensions/`. A host includes the capabilities it needs through its composition; the presence of an extension in the repository does not mean every host enables it.

- Read the [extension module overview](https://github.com/elsa-workflows/elsa-foundation/blob/main/Extensions/README.md) for the current source layout and module boundary rules.
- Browse the [extension-point index](https://github.com/elsa-workflows/elsa-foundation/blob/main/EXTENSION_POINTS.md) to find documented replacement and contribution seams.
- Use the [Elsa glossary](https://github.com/elsa-workflows/elsa-foundation/blob/main/docs/glossary/elsa.md) for framework terminology.

These links describe the repository's current development state. Check the target Elsa version and the host's composition before relying on a module or extension point.
