# Contribute documentation

The published pages in this section are Markdown files in `website/docs/` in the Elsa Foundation repository. You can propose a change through GitHub without a GitBook account; you do need a GitHub account to open a pull request. A GitBook preview may not be available to every contributor or fork.

1. Use the **Edit this page on GitHub** link at the bottom of a page, or browse the [documentation source](https://github.com/elsa-workflows/elsa-foundation/tree/main/website/docs). Keep product claims tied to the Elsa version they describe and prefer links to existing source guides over copying long explanations.
2. If you add, remove, or move a page, update `website/docs/SUMMARY.md` so navigation matches the files.
3. Check local links and image paths, then submit the change through a Foundation pull request. The [Foundation contribution guide](https://github.com/elsa-workflows/elsa-foundation/blob/main/CONTRIBUTING.md) explains the fork and review workflow.

GitHub review is the content acceptance path. Review the Markdown diff and check links even when no hosted preview is available. Fork previews were disabled in the site's settings when checked on 11 October 2026; an external-fork preview has not been demonstrated. Opening a documentation pull request does not require a GitBook editor seat. GitBook account and preview-access requirements have not been verified for external contributors.
