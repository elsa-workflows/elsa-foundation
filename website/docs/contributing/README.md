# Contribute documentation

The pages in this section are Markdown files in `website/docs/` in the Elsa Foundation repository. You can propose a change with just a GitHub account; you do not need a GitBook account or editor seat.

1. **Open the source.** Use the **Edit this page on GitHub** link at the bottom of any page, or browse the [documentation source](https://github.com/elsa-workflows/elsa-foundation/tree/main/website/docs).
2. **Make your change.** Tie product claims to the Elsa version they describe, and link to existing source guides rather than copying long explanations. If you add, remove or move a page, update `website/docs/SUMMARY.md` so the navigation matches the files.
3. **Check and submit.** Check local links and image paths, then open a pull request. The [Foundation contribution guide](https://github.com/elsa-workflows/elsa-foundation/blob/main/CONTRIBUTING.md) explains the fork and review workflow.

Content is accepted through GitHub review. Reviewers read the Markdown diff and check links, so a hosted preview is not required.

> *Good to know: previews.* A GitBook preview may not be available to every contributor or fork. Fork previews were disabled in the site's settings when checked on 11 October 2026, and a preview from an external fork has not been demonstrated. GitBook account and preview-access requirements have not been verified for external contributors.
