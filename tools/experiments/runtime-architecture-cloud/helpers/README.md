# Linux process ownership helpers

These helpers replace the captured macOS process helpers for the explicitly owned GitHub Ubuntu experiment job. They do nothing on import. `OwnedResources(out, nonce, recover=False)` and `ProcessScope(out, nonce)` retain the existing controller API, including `baseline`, `bounded`, `birth`, `key`, `install_signals`, `prove_quiescence`, `state`, and `save`. `ProcessScope` permits command starts for 540 seconds and closeout through 600 seconds from construction.

Each direct command is a new session whose Python gate waits until its kernel identity and nonce ledger are persisted. Only then can it exec the declared command. Birth identity uses Linux boot ID, PID, effective UID, and `/proc/<pid>/stat` start ticks; PPID, PGID, SID and all four UIDs are also captured. The proc directory is pinned while stat/status are read twice. Compatibility `startSec`/`startUsec` values derive from kernel boot time and scheduler ticks; they do not claim microsecond kernel resolution. They must not replace boot ID/start ticks when validating Linux identities.

`signal_exact(expected, signum, allow_controller=False)` signals only an owned exact birth. It returns `True` after a successful syscall, `False` for an absent/exited target, and raises on unknown or unauthorized identities. A crash watcher must require `is True` before recording `signalSent`. Retained pidfds prevent numeric PID reuse from redirecting signals. Only an explicitly unsupported pidfd facility uses a rechecked per-PID fallback; other pidfd failures remain unknown. Neither path signals a process group. `allow_controller` is reserved for the external stop helper and still requires the recorded exact controller birth.

Observed descendants are attributed through a live exact-birth parent or a live owned session member. A historical numeric SID alone cannot confer ownership. Unknown identities, unanchored historical sessions, and unattributed new runtime processes are preserved and prevent a quiescence claim. Polling cannot prove that no unobserved child escaped before observation: `fullLifecycleCoverageVerified` remains false. Hosted runner isolation and independent controller/container closeout receipts remain required. Helpers never release a shared slot.

Run focused controls with `python3 -m unittest discover -s tools/experiments/runtime-architecture-cloud/helpers -p 'test_*.py' -v`. Live `/proc` and gated-child controls run only on Linux; skips on other platforms are explicit. These controls do not run Elsa, .NET, or Docker.
