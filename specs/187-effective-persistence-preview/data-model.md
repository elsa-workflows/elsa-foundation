# Data model and evidence states

Read [spec](spec.md), [worker contract](contracts/candidate-inspection-v1.md) and [CLI contract](contracts/cli-inspect-v1.md). All new names here are proposed implementation shapes, not existing APIs.

| Concept | Owned by | Fields / rules |
|---|---|---|
| Captured inputs | CLI | Immutable full host SourceSnapshot plus CompositionInputSnapshot for explicit catalog when supplied (otherwise immutable bundled pin), composition, setting review and all workspace profiles. Capture each once; preserve unused profiles and sibling overlays; reject nonregular files (including Unix FIFOs/devices), symlinks/escapes/duplicates/unsupported source shapes before content reads. |
| Candidate inspection request | CLI/worker private channel | Protocol1, source enum, random invocation/capture tokens, safe shell/environment, sorted accepted/removed IDs, and selected post-edit candidate layer bytes. Host closure paths travel privately as separate existing layout metadata. Never raw input on arguments/disk/public output. |
| Candidate files | Shared Planning builder | CompositionCandidate.Files from exactly one Build call and that captured input context. Explicit removals absent from files still become overlay false; retained unknown bytes never become exported intent. SourceSnapshot instance association is internal, not caller-supplied provenance. |
| Selected host closure | Worker | Real runtimeconfig/deps pair, actual selected host assembly identity/location, existing installed package set. Configuration byte origin is independent of assembly location. No Restore or feed operation; package load failures refuse safely. |
| Selection reconciliation | Host producer | Accepted exact IDs, requested IDs after composer/defaults + candidate file merge, expanded IDs from real descriptor graph, disabled IDs and actual required edges. Unique safe IDs, case collisions refused. Accepted=requested=expanded for successful candidate inspection; removal/dependency conflicts remain explicit. |
| Resolution projection | Host producer; worker/CLI validate | Sorted per-feature/module rows: selection kind, logical resource, canonical provider, safe connection reference, selector/resource source scopes; no settings/connection values. Legacy target fields are unavailable, not inferred from registration defaults. |
| Inspection result | CLI | Complete preview plus selection plan, or stable refusal. Configuration-only scope and unverified checks survive human/JSON formatting. Existing Planning.PersistenceEvidence remains unchecked and is not promoted. |

State transitions: captured → accepted-pin checked → candidate built → inputs rechecked → explicit trusted worker → host capability checked → request validated → shell composed → selection reconciled → shared EF preparation → response content checked → all inputs rechecked → safe preview. Any failure goes to refusal with cleanup; there is no save/activate/publish state. A random private invocation token correlates one live exchange; it is not a fingerprint, signature, byte-equality proof or reusable acceptance receipt.

Legacy mode has no invented logical resource, provider or connection reference. The shared resource preparer deliberately represents legacy target presence without resolving feature registration defaults. Its empty resource patch remains runtime-compatible; legacy-target-unprojected is a visible limitation. Broader legacy effective-settings inspection remains #1962 work. Resource-mode configured-value checks match runtime preparation for supported captured inputs, not a deployed runtime observation.
