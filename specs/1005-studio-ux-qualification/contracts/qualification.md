# Qualification contract

The [#3075 finite matrix](https://github.com/elsa-workflows/elsa-foundation/issues/3075) owns journey acceptance. No new product API or public React export is introduced.

1. Evidence is bound to exact source/build and selected journeys.
2. Every browser/API write has a reviewed purpose, private origin, owned target, bounded size/count and observed status.
3. Real engine execution, loaded non-sensitive payloads, actual scheduler attempts and authenticated diagnostics are required where specified.
4. Successful private feature Apply is verified independently against the exact intended configuration delta; Cancel preserves configuration.
5. Screenshot and asset receipts are reviewed by root. All owned hosts, browsers, credentials and temporary data are removed, and source configs remain unchanged.
6. Source-only preparation, historical leaf receipts and route-mocked controls retain their limits.
7. Required checks, separate application approval and resulting-main verification precede closure. Unresolved blockers remain explicit.
