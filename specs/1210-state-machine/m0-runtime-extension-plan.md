## Success and scope

The normal native runtime must durably accept exact invocation inputs without activating unrelated authored inputs, direct work to live ordinary visit owners, and close a same-source trigger group only after every exact recipient and runnable continuation is accounted for. Actual HTTP fan-out, saved publications, normal native work and cold persisted recovery must establish those facts. Keep source claims, execution writers, checkpoints, queue/outbox delivery, lexical frames, faults and value retention under their existing owners.

Included: generic versioned source/target models and reducers, physical participants and readiness, native admission/control callbacks, causal propagation and source sealing, query/retention/terminal projections, and source-bound positive/negative integration evidence. Excluded from this unit: production StateMachine activity/designer, complete chart selection engine, full Studio journeys, saga example, deployment/release or a new authored asset/model lifecycle. Those remain required subsequent program work, not deferred first-release scope.
