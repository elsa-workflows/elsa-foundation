# Portable/private model

The approved implementation contract is [portable-input-v1](contracts/portable-input-v1.md).

| Entity | Fields and relationships | Validation |
|---|---|---|
| Public envelope | Version/kind; unchanged inner authored v1; exactly one input ID/revision; origin/replacement disposition | Strict fields, duplicate rejection, safe reviewed content before publication |
| Required private input | Complete supported Workbench configuration bundle supplied by operator | Fixed context, complete case-safe inventory, exact bytes and regular-file limits |
| Private input receipt | Version/kind; IDs/context; exact public digest; complete file-name/byte-hash inventory | Private context matches supplied bundle; IDs/revision/public digest match envelope; never public |
| Invocation capture | Frozen envelope/receipt/bundle/review/catalog/workspace profiles | Recheck every file and full supported inventory before publication |
| Private candidate receipt | Fresh candidate ID; input ID/revision; public digest/private context/disposition; generated-file inventory | Matches actual generated bytes; separate from installed host files |

## States

Unreviewed source → redacted import preview → accepted public envelope/private input receipt, published together in a fresh artifact-pair directory. No bundle/credential bytes are automatically exported; operators separately provide the private bundle.

Accepted envelope + matching supplied bundle/receipt → redacted generation preview → fresh candidate/private candidate receipt. Inputs must remain unchanged before publication.

Different complete bundle → explicit rebind preview → new replacement envelope/receipt/revision → separate generation review. Existing artifacts remain unchanged. Same revision with different inventory refuses.

Absent/mismatched/drifted/unreviewed/unsupported input → fixed refusal with no partial publication. Configuration is deterministic for unchanged accepted inputs; new association UUIDs are random, not content hashes.
