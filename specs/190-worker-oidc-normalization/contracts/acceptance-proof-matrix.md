## One coherent actor proof

Use the same rebuilt feature composition for the valid-grant, invalid-token, forged-claim, no-grant, same-token rule-update and fresh-restart cases. Observe selected shell and mounted Runtime routes, active features, distinct normalized type and both store targets. Call actual execute and stimulus endpoints with a persisted artifact/bookmark, query persisted runtime status and inspect IAM state. Do not substitute direct dispatcher invocation or a header-based fake handler. Test setup may provision schemas and seed rules/artifacts; bearer requests must not do so.

## Restoration and source qualification

Run one bounded mutation at a time on the production handler/options/guard path, not in the assertion or fake fixture. Record unchanged baseline, failing mutated control, exact restoration and passing affected suite. Do not count a green synthetic unit as real JWT wiring or a database suite as an external IdP deployment. Keep current-head and resulting-main workflow evidence separate, retain failures/skips and report exact project/count only when actual logs provide it.
