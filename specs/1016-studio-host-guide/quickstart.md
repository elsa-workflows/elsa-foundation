# Validation quickstart

Use a fresh actual Studio CI qualification artifact and the sample/guide from this work unit. Select only originals under `studio-nuget/` and `studio-modularity-nuget/`; the artifact also contains private fault mutants that must never enter the developer feed.

1. Follow the canonical developer recipe in an isolated folder, using its exact candidate version and explicit preview sources.
2. Restore, repeat locked restore, publish and inspect package-only dependency/DLL provenance with frontend commands denied.
3. Hide this run's source, feed and cache. Run the published app and observe the standard shell, selected Dashboard module, discovery, runtime configuration and assets. Browser automation is an external observer; the consumer must invoke no frontend tool.
4. Trace guide statements and all four report links to accepted source and M0–M3 delivery receipts, preserving known limits and failed/skipped/superseded results.
5. Run architecture graph/whole guards/discovery, maps and link checks, converge independent review, then require exact-head and resulting-main checks/artifacts/sample before final issue/board closure.
