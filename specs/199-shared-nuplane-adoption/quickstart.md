# Validation Guide

This is preparation guidance, not evidence that a command has passed.

1. Read [research](research.md) and resolve the exception-observability prerequisite before implementation-ready tasks. Inspect current competing #2314 claims/PRs before committing source.
2. Use an owned qualification copy and actual audited public CShells `.169` / Nuplane `.99` (or an explicitly qualified corrective preview), keeping canonical committed preview pins unchanged. Record cache/archive/source/loaded DLL identity and every command exit.
3. Through the normal build-slot wrapper, build/test only the touched projects. Focus Modularity tests on both legacy profiles, actual configuration Reload tokens, existing Workbench regression assertions, cold Begin freshness, real host composition identity and autoload ordering. Run the relevant Cluster/EF refusal proof against rebuilt owned hosts when the qualification environment is ready. Check host load before diagnosing timing failures.
4. Preserve each existing assertion and public test objective when repairing fixtures; ordinary refresh/reload failures use the real Nuplane dispatcher/logger, never a test catch shim. Direct cancellation remains a direct observer test.
5. Before final adoption, verify the actual stable release families and update central pins, reached locks, Docker reference graph and maps together. Run affected architecture tests and `dotnet run --project tools/maps/Elsa.Maps.Generator -- check`.
6. Rebuild and run owned real Foundation.Host and Workbench with fresh databases; prove package install/update/removal, Foundation reload-on and Workbench reload-off/opt-in, refusal retention, later eligible recovery and cold build freshness. Run relevant `e2e-tests/` suites against those rebuilt hosts.
7. Run `bash tools/demo/rehearse.sh` for frozen Acts1/2 acceptance. Inspect its prerequisites and owned temporary resources before execution; preserve command output and failures. This supplements actual-host and backend E2E proof.
8. Require root/independent source review, appropriate causal mutations, exact-head CI/maps/architecture and resulting-main checks. Copilot is unavailable and Greptile optional under D15. Do not call preparation stable adoption or close #2314 before every final gate is proven.
