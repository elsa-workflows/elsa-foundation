# Qualification report model

No new production or persisted domain model. Reports retain composition name and selected packages/features; source/tool/driver SHA256 and producer provenance; real archives/cache/published DLL/resource hashes; locked package-only graph and hidden build inputs; explicit deployed runtime feed/store admission identity; HTTP/browser/auth observations; pre/post serving-generation and stream-marker evidence; restart/storage/source hashes; control stage/cause and restored outcome; frontend invocation audit and owned process completion.

Profile states are planned, packed, restored, published, running and qualified/failed. A deliberate failed consumer stays failed; a separate expected-failure assertion plus restored normal run qualifies its guard. Local qualified profiles, reviewed source/CI delivery and actual resulting-main verification remain separate states. Credentials in this fixture are synthetic sentinels; reports never require real secrets.
