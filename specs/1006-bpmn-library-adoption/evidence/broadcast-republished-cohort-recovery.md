# Saved publication recovery after republish and actual collection

This bounded T051 case qualifies collection after cohort acceptance, replacement of the selected
publication, and recovery of its exact original start through the standard Foundation host.
T051 remains unchecked. Other GC/acceptance race orders, historical upgraded-host recovery,
final Studio, deletion, delivery and production acceptance remain open.

The source parent is `d909b25ae28d87e359889063a91b979bf8ff8e4a` with an explicit worktree
candidate suffix. The [machine receipt](broadcast-republished-cohort-recovery.json) binds six
harness/reader files and three actual receipts. Each passing case verifies the same **1,381**

The standard binary contains no recovery probe. Whole databases/configuration remain private.

## Actual sequence and attribution

1. Normal authenticated APIs publish the selected signal-start artifact, arm two parallel
   catches, publish a separate unmatched collection control and execute the signal publisher.
   The actual host saves one complete one-start/two-resume cohort and holds before dispatch.
2. Public version ingest creates a new version of the selected definition. An explicit Replace
   publish, conditional on the original publication ID, installs a **different artifact and
   publication in the same definition/default slot**. Public unpublish retires the unmatched
   control. Later matching waits and a different binding are also created.
3. Independent coherent snapshots, read through the actual checked EF stores, must show the
   original material still present and **only its exact retired reference**, the distinct new
   active binding/reference, and the unrelated control physically present but retired. None of
   those three artifacts has an execution yet. The old artifact has no execution or dispatch
   retention root and no incoming declared executable dependency.
4. The inventory also checks wrapper and fully flattened node template-hash references, and
   every installed template's direct, closed and metadata dependency routes. This fixture has
   **33 standalone catalog templates**; they are allowed only without these edges or an identity
   alias to the old artifact. Thus indirect roots or uncertain template reachability cannot
   explain retention of the old workflow artifact. Missing inventories or projections refuse.
5. The normal GC pump runs its **actual selected collector**, with configured zero creation
   grace. A test-only wrapper forwards its retention capability, both sweep overloads and real
   results. It holds scheduling until all publication/root writes finish, then releases the
   actual sweep. This preserves the normal staging-to-first-root window before the zero-grace
   experiment; it does not fabricate a sweep, clock, claim, provider result or application row.
6. The real sweep deletes **one unrelated artifact and one source reference**. Independent
   checked state must prove those exact control rows disappeared while the original artifact
   and retired reference remain. The entire checked owed source projection stays unchanged.
   An active replacement, broad retain-everything fallback or staging grace cannot supply this
   result. Ordinary public execution with the original retired source returns **HTTP 409**;
   the bounded response is captured in the machine receipt.
7. The owned process is killed before recipient dispatch. A standard host with no probe
   reclaims under a distinct owner and fence **1→2**, completes the two original callbacks/join,
   and parks exactly the saved keyed start. Its physical state pins the **original artifact
   ID/hash, source reference, publication and definition version**. The replacement, collection
   control and later binding stay unstarted; later exact waits stay unchanged. The saved cohort
   is identical through collection, crash and recovery.

This proves the old artifact was genuinely owed and unstarted while actual collection ran,
then recovered through saved authority after ordinary publication admission had ceased. It
qualifies this order only; production retention policy and the reverse GC/acceptance order
are separate evidence requirements.
