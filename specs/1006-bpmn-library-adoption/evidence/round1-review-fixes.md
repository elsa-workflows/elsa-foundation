## Preserve persisted responsibility

The old codec allowed absent/null semantic collections to become constructor defaults. On the actual waiting-B compensation payload, omitted replay state could lose the pending B/A responsibility. The reader now validates the qualified persisted writer layout before deserialization: required collections, flags and nullable members; nested replay lists, registration status, token role/parent identity, race and loop fields; enum/record/ID shape and uniqueness. Replay IDs must identify claimed registrations and the coordinator/current handler association must remain exact. Pending fault handling and legitimately pruned ordinary ancestors/history remain distinct. The reader preserves ordering and explicit null collection items. Conflicting case-insensitive record members cannot shadow validated members; opaque data and string-map keys retain exact casing.

The [writer profile contract](../contracts/compatibility.md#qualified-persisted-writer-profiles) names the complete actual d81/current profiles. Version 1 keeps its alias/version/wire names and permits its original missing invocationCorrelation/stoppedHandle. Earlier additive v1 layouts cannot be inferred from the version alone: ambiguous omissions refuse intact instead of being guessed empty. New in-memory library state can still use constructor defaults. Transitions and pruning remain library-owned.

The embedded codec fixture is a derived view of the unchanged actual old-writer whole module backup. [Read-only verification](round1-fixes/verify_codec_fixture.py) checks both source hashes and exact payload equality. This is a codec regression fixture; actual host recovery remains a separate complete-store witness.

## Canonical saved-start input

Direct saved-start admission previously validated source/key/scope but accepted arbitrary caller stimulus input. The dispatcher now shares the owning request projector with source routing, reads the provider's canonical immutable intent, validates its cohort and binds stimulus input/requested-by identity before duplicate lookup, policy or actor effects. The runtime registration factory supplies the registered decoders. Every previous CLR constructor remains; construction without decoders grants no saved-source capability. Ordinary starts keep their existing path. One additive constructor is declared in the existing public API file. Runtime continues to use the owning adapter instead of decoding Primitives payload fields.

Direct regressions cover changed/missing input in both providers, before a new start and before an existing keyed duplicate, plus changed caller identity. The positive dispatch assertion checks the command's actual input against its persisted source. Finite start fixtures now contain their complete start-only cohort and use an explicit owner decoder; the unpaired UTF-16 refusal control is retained.
