All commands are recipes until their actual source-bound receipts are recorded on #3440 and its PR.
Use normal build-slot scheduling, new owned output roots and unique local versions. Check machine
load before interpreting timing failures. Do not use existing developer credentials or change a
provider configuration to obtain deterministic protocol evidence.

## Causal module and UI baseline

1. Pack the separate Acme size contribution against retained product packages/public SDK. Run its
   native-service-backed tests and preserve all existing visibility/workflow controls.
2. For each actual provider adapter, prove unchanged FullAuto permits the eligible size effect once
   with independent native revision/size/full-layout readback. Prove unchanged Manual requires review
   and leaves the owner unchanged until approval. Reads establish each conversation first.
3. On unchanged production policy behavior, select FullAuto -> Manual in the real dock and request a
   non-no-op size change in the same existing conversation. Retain the actual mismatch if observed.
   Repeat Manual -> FullAuto with a separate established idle conversation. Wrong-cause failures,
   a missing update route or a new conversation are not a causal baseline.
4. Record those outcomes immutably as baseline evidence. Select/implement the smallest owner and
   acknowledgement contract, then repeat the same semantic expectations. No contract freezes before
   both real adapter/package paths prove it.

direct preparation/proposal creation, retained review, pre-dispatch approval, pending/uncertain ACK
and receipt-continuation races. Compete policy changes in both directions. Verify distinct,
identical and conflicting deliveries; losing transitions are explicit and no provider/effect repeats.
Test cancellation and contributor/cleanup failure, lost update response/readback, stale response
generation, unknown mode, current ceiling and preservation of restrictive unrelated server policy.

zero pre-dispatch execution/effect and correlated audit; uncertainty after dispatch cannot be
