# Qualification journeys

Run against an owned, rebuilt Studio/Workbench composition and disposable data. Never stop a process the run did not start. Capture source head, composed features, resource/version IDs and safe evidence; do not commit credentials or private payloads.

1. Author baseline Sequence steps reading parent/ancestor variables, consuming a prior activity result and producing a result used by a later step. Execute and record outputs/effects.
2. Extract the middle steps as Prepare shipment, open/edit/rename/return, save/reload, Undo/Redo and execute. Compare baseline behavior and inspect the block plus children.
3. Repeat on linear Flowchart and the Activity Definition graph host. Include a block within a loop and distinct producer occurrences; preserve nearest-loop Break and nearest-graph Complete semantics.
4. Extract an eligible same-lane BPMN task region into a real subprocess. Save/reload/run, export/reimport and audit IDs, task bindings and DI independently of render success.
5. Exercise representative refusals before mutation: discontiguous Sequence, graph crossing/custom exit, trigger, BPMN boundary/gateway/direct-model, block-local declaration on Ungroup, and missing catalog/permissions.
6. Wait inside a block, resume after persistence/restart, cancel another waiting run, and fault/recover a supported child. Confirm expected outputs and exact child occurrence evidence.
7. Promote a typed-reference example, review the public interface/bindings, create a normal draft, validate/publish, resume with an exact published version and replace. Run two independent call sites. Undo replacement and confirm the shared definition still exists.
8. Change the source/target while preview is open; deny a permission, fail publication and supply an opaque expression/external write. Confirm source remains intact.
9. Repeat relevant navigation/operations in light/dark themes and narrow layouts using keyboard focus. Check read-only/source-owned/historical documents and missing optional modules.
10. Retain an older published/running version, edit the new draft and confirm historical material and frozen names remain unchanged.

Tests use the cheapest meaningful level, with red/green bite proofs for behavioral changes. Run complete affected frontend/backend suites, relevant backend source journeys, architecture and generated-map gates; compare executed counts with inventory. PR CI and resulting-main qualification are separate receipts.
