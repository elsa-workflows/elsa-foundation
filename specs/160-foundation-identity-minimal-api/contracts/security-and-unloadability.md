# Security and Unloadability Contract

The capabilities endpoint names only `identity.providers.read`; exact, implied, wildcard, and normalized external claims are evaluated by Foundation Identity. Anonymous access returns 401 and authenticated denial returns 403. Token issuance authenticates only through configured interactive schemes and rejects first-party bearer exchange. Both owners must release route, authentication/provider, DI, serialization, and disposal references across repeated collectible-context cycles.
