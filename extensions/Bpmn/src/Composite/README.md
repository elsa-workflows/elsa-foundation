# Elsa.Activities.Bpmn.Composite

The `ActivitiesBpmn` feature composes the existing BPMN composite activities and their authored trigger bindings over the workflow contracts. The [BPMN module documentation](../Elsa.Activities.Bpmn/README.md) describes configuration and supported behavior. Hosts with explicit assembly selection can discover the feature through `typeof(ActivitiesBpmnFeature).Assembly`.
