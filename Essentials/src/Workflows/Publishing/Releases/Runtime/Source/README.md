# Runtime release source closure

Optional source-side member acquisition. Hosts select exactly one source namespace and export policy;
there is no permissive default. The contributor expands exact Runtime native/model/template dependencies
using qualified bounded readers. Renewable physical leases protect native/model material through the awaited
callback. Template acquisition produces bounded owned copies; it does not acquire material leases for templates.
It does not select published roots, import owner catalogs, or grant activation authority.

Target-only Runtime codecs remain in the separate parent package and acquire no source/capture dependency.
See [extension contracts](EXTENSION_POINTS.md) and [delivery slices](../../../../../../../specs/1225-workflow-release-promotion/delivery-slices.md).
