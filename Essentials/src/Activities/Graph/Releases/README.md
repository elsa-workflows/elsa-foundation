# Reusable Graph release inspection

Select `ActivitiesGraphReleaseVerification` alongside the Runtime release profile and Graph Runtime consumer.
This optional owner adapter reads captured members only. It checks the existing single-entry, closed Graph
plan, original provider data, public contract links, child occurrence overlay and placed descriptor identity.
Structural authored trees, richer bindings and unknown schemas refuse until their owner profile is qualified.
It does not recompile a body or grant source/target access. Placement and CLR capability checks stay mandatory.

Runtime overlay sites are qualified by the actual template-root consumer. The Graph adapter owns only
`elsa.graph-activity` overlay inspection and checks the overlay schema explicitly; unrelated consumers can
register independent strategies. The transport manifest and owner payload bytes do not contain these discovery
keys and are not rewritten. Runtime discovery capability version 2 advertises this ownership change.

The executing Graph Runtime project keeps its existing Runtime-only dependency boundary. This optional adapter
carries the compiler-free release Core dependency; no Design, Publishing compiler or concrete store is loaded.

Cross-domain release inspection is contributed through the Releases.Core exact-key strategy; see the
[registration and replacement catalog](EXTENSION_POINTS.md). Graph execution and Design publication remain
separate features. The bounded placed-input profile requires every child input to be explicitly bound;
implicit optional/default lowering is refused until independently qualified.
