# Primitive release inspection

Select `ActivitiesPrimitivesReleaseVerification` alongside the Runtime release profile and the primitive activity
module. This optional owner accepts the bounded `WriteLine` CLR profile only; other primitive types remain
Unsupported until independently qualified. It checks the frozen contract, atomic result, exact activation alias,
replay semantics and supported input shape without executing an activity or recompiling it.

Cross-domain release inspection uses the Releases.Core exact-key strategy; see the
[registration and replacement catalog](EXTENSION_POINTS.md). Generic binding/resource inventories and placement
associations remain independently mandatory. Graph wrappers require their separate Graph owner. Approval grants
no source access, target import, compatibility admission or fresh-start authority.
